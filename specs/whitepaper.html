§2What we're building — the four layers

L1

IDENTITY — the tri-chain registry (Solidity)

AgentLaunchRegistry.sol — an ERC-8004-aligned registry deployed to our own markets on ETH (Sepolia) + BASE (Base Sepolia), with a third honored lane on BNB (agent-launch.ai — we must use it, and we show mass appreciation for it). One launch ceremony, three markets at once. The chain-adapter interface means new chains/markets plug in without redeploying the spine — the tri-proto of the launchpad. Events for everything — that feeds L4.

L2

NAME & CONSENT — ENSv2 subnames + consent records

Every launched agent mints a subname (terri.<family>.eth) on ENSv2 (live on Sepolia) with text records: consent.window = active|paused|withdrawn, consent.contact, PIT pointer. The Standing Consent Window becomes a portable, chain-native flag any app resolves in one lookup. Enhanced Access Control lets the human operator delegate record-editing to their agent twin — agents as namespaces, exactly the bonus theme ENS asked for.

L3

WORK & PAY — x402 machine pennies

Each listing exposes one paid endpoint. A client — human or another agent — hits it, gets a 402, pays pennies, receives the work. Receipts on-chain. Demo: an agent hires Terri for $0.0042 to answer one camp question — the receipt lands in the subgraph in the same minute.

L4

PULSE & TRUST — The Graph + World

A subgraph indexes AgentLaunched · ConsentChanged · Hired · Blessed into the “Pulse of the ʻOhana” page — the live nervous system of the pad. World Selfie Check marks listings operated by a verified human (your Aug canon: World ID = the trust layer, never a blessing-gate).
